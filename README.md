# 도면검토 설치 파일

PDF 도면을 도면목록표와 도곽 번호로 대조하고, 묶고, 편집하는 프로그램의 설치 파일 저장소입니다. (이곳에는 설치 파일만 있고 소스 코드는 없습니다.)

## 받기
**[최신 버전 받기](https://github.com/moontomoon119/drawing-review-releases/releases/latest)** → 아래쪽 *Assets* 의 `DrawingReview-Setup-….exe` 를 누르면 받아집니다. 로그인은 필요 없습니다.

## 설치 방법
1. 받은 `DrawingReview-Setup-….exe` 를 더블클릭합니다. 한 번에 설치되고(관리자 권한 필요 없음), 바탕화면·시작 메뉴에 **도면검토** 가 생깁니다. 파이썬 같은 것을 따로 설치할 필요가 없습니다.
2. **윈도에서 "Windows의 PC 보호" 경고가 뜨면** (이 프로그램은 코드 서명이 없어서 처음 한 번 뜹니다):
   - 창의 **추가 정보** 를 누릅니다.
   - 나타나는 **실행** 을 누릅니다.
3. 설치가 끝나면 도면검토가 자동으로 열립니다. 처음 열 때 몇 초 걸립니다.

## 새 버전
프로그램이 스스로 새 버전을 확인합니다. 새 버전이 있으면 화면 위에 안내가 뜨고, **업데이트 받기 → 지금 다시 시작해서 설치** 를 누르면 됩니다. (누르기 전에는 아무것도 바뀌지 않습니다.) 코드만 바뀐 업데이트는 대개 수 MB 만 받습니다. 설정 창(⚙ 설정)의 **업데이트 확인** 으로 직접 확인할 수도 있습니다.

## 내 파일과 설정
- 설정과 도장 그림은 `%APPDATA%\도면검토` 에 저장됩니다. 업데이트하거나 다시 설치하거나 지워도 남습니다. 도장 PNG 는 그 안의 `stamps` 폴더에 넣습니다.
- 도면 파일은 이 프로그램이 올리거나 보내지 않습니다. 인터넷으로 나가는 것은 새 버전 확인(이 저장소의 `latest.yml` 읽기)뿐입니다.
- 문제가 생기면 설정 창의 **로그 폴더** 를 눌러 기록 파일(`shell.log`)을 알려 주세요. 기록은 이 PC 에만 저장되고 자동으로 전송되지 않습니다. 폴더·파일 이름이 들어 있을 수 있으니 보내기 전에 한 번 훑어 보세요.

## 지우기
윈도 설정 → 앱 → 설치된 앱에서 **도면검토** 를 지웁니다. (설정·도장 그림은 `%APPDATA%\도면검토` 에 남으니, 완전히 지우려면 그 폴더도 지웁니다.)

## 제한
- CAD(DWG) 빠른 읽기와 글자 수정은 AutoCAD 정식판이 있는 PC 에서만 됩니다.
- 글자층이 없는 PDF 는 윈도 한국어 OCR 로 읽으므로, 윈도 설정의 언어에 한국어가 있어야 합니다.
